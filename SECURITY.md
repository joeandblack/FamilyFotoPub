# Security policy

Please report suspected vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/joeandblack/FamilyFotoPub/security/advisories/new). Do not include passwords, backup keys, personal photos, or other private library data.

Include the affected version, operating system, reproduction steps using synthetic data, and the impact you observed. Please avoid public issues or pull requests that disclose an unpatched vulnerability.

Security fixes target the latest code on `main`. Older versions and experimental branches do not receive separate security maintenance; update to a release containing the fix when one is available.
