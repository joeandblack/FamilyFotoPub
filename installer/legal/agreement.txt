2. What is installed

FamilyFoto Setup installs the FamilyFoto application and, inside its installation folder:
- a private Python 3.12 runtime and the Python libraries FamilyFoto uses,
- PostgreSQL 17, the database that holds the catalog,
- FFmpeg, which converts and reads videos (on Windows, setup downloads it from www.gyan.dev
  during installation; the Windows release does not include it),
- the setup window,
- and, only if you include People, face-recognition libraries and face models (section 4;
  setup downloads those libraries during installation).

Each component remains under its own licence. The release manifest lists every component with
its licence, and the licence texts are installed with the components (on the Mac, for PostgreSQL

5. Downloads and your data

Setup downloads FamilyFoto and the components above from FamilyFoto's GitHub releases and checks
every file against the checksum recorded for this release; an offline installer carries them
instead. On Windows, setup downloads FFmpeg from www.gyan.dev, also during an offline
installation, and checks it against a pinned checksum. If you include People, setup downloads its
Python libraries from the Python Package Index (section 4), also during an offline installation. After setup, FamilyFoto runs on your computer: your photos, videos and catalog stay
there, and FamilyFoto does not send them, or reports about them, to the FamilyFoto developers or
anyone else. Face recognition runs locally and never downloads anything. Anyone you give an
account to, or who can reach FamilyFoto on your network, can see what that account allows.
